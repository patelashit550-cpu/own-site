Place your essays in `ontology/writing/`. Each file needs YAML frontmatter at the top.

The `stage` field controls where a file appears:

- `draft` — local development only
- `review` — preview builds
- `published` or `canonical` — the public build

To add an image, set `image`, `imageAlt` and `imageRole` (`inset`, `figure` or `plate`). With `inset`, the title and image stay on the left on desktop while the text scrolls on the right.
